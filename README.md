# AudioSlots
Highly intuitive audio controlling application. The application runs on Windows, Linux & MacOs; Bringing a highly inticipated control scheme to your desktop platform. 
The app features 5 slots which you gamble with the current audio percentage you have in hopes at winning big audio. Very cool.
